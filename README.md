# Likun Zhang — Academic Homepage

Personal academic homepage and blog for
[liquidzk.github.io](https://liquidzk.github.io/). The site is deployed from the `main` branch with
GitHub Pages and uses Jekyll only for Markdown articles.

## Publish an article

1. Copy `_drafts/article-template.md` to `_posts/YYYY-MM-DD-your-title.md`.
2. Update the front matter and write the article in Markdown.
3. Commit and push to `main`. The article and its link in `/blog/` are generated automatically.

The filename date must use `YYYY-MM-DD`, and future-dated posts are not published until that date.
